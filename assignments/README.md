# 📂 Entregas de Tareas (Assignments)

Para mantener el repositorio de la clase organizado y evitar la saturación de archivos sueltos, **es obligatorio que cada alumno trabaje dentro de su propia carpeta personal**.

## 📌 Reglas para subir tus tareas:

1. **Crea tu carpeta personal:** Dentro de este directorio (`assignments/`), crea una carpeta con el formato `Apellido_Nombre` (ejemplo: `Hernandez_Alessandro`).
2. **Todo va en tu carpeta:** Todos tus cuadernos de Colab (`.ipynb`), scripts de Python/R, y las imágenes resultantes de tus análisis deben guardarse **exclusivamente** dentro de tu carpeta personal.
3. **No dejes archivos sueltos:** Cualquier archivo entregado fuera de una carpeta personal será eliminado o no será evaluado.
4. **Nombres de archivo claros:** Cuando subas una práctica, usa nombres descriptivos (ej. `Practica_01_Pandas.ipynb`).

*Nota: Si estás haciendo un Pull Request, asegúrate de que tus "commits" solo incluyan modificaciones dentro de tu carpeta.*
