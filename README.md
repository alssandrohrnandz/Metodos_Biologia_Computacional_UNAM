# Métodos de Biología Computacional

Bienvenidas y bienvenidos al repositorio de la asignatura **Métodos de Biología Computacional**. Este espacio contiene las guías prácticas, códigos de demostración, ejercicios en clase y asignaciones para el bloque de clases de la materia.

## 📋 Descripción del Curso

El objetivo de este bloque es dotar a los estudiantes de herramientas algorítmicas, estructuras de datos avanzadas, modelado numérico y simulación estocástica aplicadas a problemas en genética de poblaciones, dinámica de ecosistemas y biología celular.
